# Writing style

The project owner does not want copy (in this repo's app, brand materials,
docs, or any other written content) to read as AI-generated. Concretely,
avoid:

- Contrastive-negation clichés: "X is this... not a that," "not a Y, but a
  Z," stacking more than one such contrast in the same passage.
- Rhythmic list cadences that sound generated, e.g. "8 colors, 3 jobs,"
  "three things, one thing," a number-led enumeration used as an opener.
- Vague abstraction-filler verbs standing in for a real description:
  "everything sits on...", "is carried by...", "is built on...", "made
  concrete."

Prefer plain, concrete, literal statements. Say directly what something is
or does instead of reaching for rhetorical contrast or singsong parallel
structure.
